# 国内外股票基金/ETF 投资策略手册

**版本**：v1.0（2026-10）｜ **适用对象**：投资期限 3-10 年、最大回撤容忍 20-30% 的积极型个人投资者
**工具**：场外基金（主）+ 场内 ETF（辅）｜ **体系**：核心-卫星 + 四维信号打分卡
**重要声明**：本手册为规则框架与个人研究工具，不构成投资建议；所有基金/指数代码仅为示例，交易前请自查最新费率、规模与公告。

---

## 1. 投资目标与约束

| 项目 | 设定 | 含义 |
|---|---|---|
| 投资期限 | 3-10 年 | 中期资金，可承受跨年度的估值波动周期 |
| 风险偏好 | 积极（回撤容忍 20-30%） | 股票仓位运行区间 60%-85% |
| 收益目标 | 年化 8%-12%（不保证） | 超额来源：全球分散 + 估值纪律 + 卫星轮动 |
| 操作风格 | 核心-卫星 | 70-80% 纪律化底仓 + 20-30% 信号驱动 |
| 主要工具 | 场外基金为主，ETF 辅助 | 场外支持自动定投；ETF 用于盘中交易与折溢价套利观察 |

**三条铁律**（先于一切规则）：
1. **不加杠杆、不做空、不买单日热点**；
2. **任何买卖必须能对应到本手册的一条规则**，否则不做；
3. **数据不更新就不决策**（信号过期 > 10 个交易日时暂停调仓）。

## 2. 总体框架：核心-卫星

```
组合 100%
├── 核心仓 75%（战略配置，长期纪律化定投+再平衡，几乎不择时）
│   ├── A股宽基 25%（沪深300 / 中证500 / 创业板指）
│   ├── 海外宽基 20%（标普500 / 纳指100，QDII）
│   ├── 防守型股票 5%（中证红利）
│   ├── 债券 15%（纯债基金 / 同业存单指数 / 国债ETF）
│   ├── 黄金 8%（黄金ETF联接）
│   └── 现金/货基 2%（承接卫星未选中的预算）
└── 卫星仓 25%（信号驱动，规则进出）
    ├── 行业卫星 10%（动量前 3 名：4% / 4% / 2%）
    └── 国别卫星 15%（恒生科技 8% / 日经225 7%，趋势门槛制）
```

为什么这样设计：
- **宽基为盾**：A股+海外宽基分散单一市场风险；A股与美股长期相关性低（但在全球危机中同跌，故再配债券+黄金对冲）；
- **红利为缓冲**：中证红利低波动+高股息，熊市回撤显著小于成长宽基；
- **债券+黄金为压舱石**：合计 23%，是回撤控制在 20-30% 的主要来源；
- **卫星为矛**：行业与国别轮动用强规则限制在 25% 以内，错了伤不了根基。

### 3.2 基金筛选标准（买之前逐条核对）

**场内 ETF**：
1. 规模 ≥ 2 亿（防清盘），日均成交 ≥ 1000 万（流动性）；
2. 跟踪误差年化 ≤ 2%（宽基）；
3. 管理费+托管费：宽基 ≤ 0.6%（现在主流宽基已有 0.2% 产品）；
4. QDII 类额外检查**溢价率 ≤ 3%**（引擎会自动标红，超限拒买）。

**场外基金**：
1. 优先选**指数基金/指数增强**，主动基金只作为卫星补充且需 3 年以上业绩；
2. 持有期 > 1 年选 **A 类**（申购费打折后通常更省）；< 1 年选 **C 类**（免申购费但有销售服务费）；
3. 规模 ≥ 2 亿、成立 ≥ 2 年、基金经理任职稳定；
4. 同一指数只持有一只（避免伪分散）。

## 4. 四维信号体系（全部定量）

### 4.1 估值面（权重 40%）—— 决定"买多少"

用指数 **PE-TTM / PB 过去 10 年滚动分位数**（美股标普500用席勒PE 15年分位）：

| 分位区间 | 状态 | 定投倍数 | 动作 |
|---|---|---:|---|
| < 20% | 低估 | **2.0x** | 积极加倍定投 |
| 20%-40% | 合理偏低 | **1.5x** | 加量定投 |
| 40%-60% | 合理 | **1.0x** | 正常定投 |
| 60%-80% | 合理偏高 | **0.5x** | 减半定投 |
| ≥ 80% | 高估 | **0.0x** | **停投**；核心宽基进入分批止盈观察 |

- 组合层规则：沪深300 分位 ≥ 60% → 股票仓位上限降到 70%；≥ 80% → 降到 60%（超限部分 70% 入债、30% 入现金）。反过来，低估时上限放宽到 85%。
- 恒生科技/纳指等无长期官方 PE 的指数，引擎用**价格分位**替代并明确标注（弱均值回归假设，只作参考）。

### 4.2 趋势/技术面（权重 30%）—— 决定"什么时候不能买"

- **200 日均线牛熊界**：收盘价在 200 日线下方 → 该资产趋势分打折，国别卫星直接不入选（预算回流现金）；
- **12-1 月动量**（学术标准动量因子：过去 12 个月剔除最近 1 个月，规避短期反转）：
  - 行业卫星按动量排名取前 3 名（4%/4%/2%），且**趋势分 ≥ 50 才有资格**；
  - 排名每月更新，跌出前 3 的行业下月调出。
- 趋势分构成：均线位置 60 分 + 动量强度 40 分（tanh 压缩到 0-100）。

### 4.3 资金面（权重 15%）—— 辅助确认"情绪在哪一侧"

| 指标 | 用法 |
|---|---|
| 两融余额 20 日变化 | 上升 = 风险偏好回升（加分），骤降 > 5% 警惕 |
| 指数成交额 20日/120日 均值比 | > 1.3 且处于高位 = 情绪过热信号 |
| **QDII 溢价率** | 场内溢价 > 3% **拒买**（改场外或等回落）——历史上纳指 ETF 溢价曾达 20%+，追高必亏 |
| 美债 10Y 利率 3 个月方向 | 快速上行压制全球成长股（海外资产减分） |
| 北向资金 | ⚠️ 2024-08 起停止实时披露，不再作为信号，用两融+成交趋势替代 |

### 4.4 宏观面（权重 15%）—— 决定"大环境顺风还是逆风"

**中国资产**（PMI / 社融滚动同比 / M1-M2 剪刀差 / PPI）：
- PMI > 50 且连续回升 → 顺周期加分；
- M1-M2 剪刀差走阔（资金活化）→ 企业盈利预期改善；
- PPI 回升 → 工业利润修复；
- 宏观分高利好权益；宏观分低时债券相对受益（债券的宏观分取反向）。

**海外资产**：美债 10Y 利率 3 个月变化（下行利多成长股）+ 席勒 PE 分位（估值维度内）。

### 4.5 打分卡合成

```
总分 = 40% × 估值分 + 30% × 趋势分 + 15% × 资金分 + 15% × 宏观分（缺项自动归一）
```

| 总分 | 解读 | 默认动作 |
|---|---|---|
| ≥ 65 | 偏多 | 按估值倍数定投/持有 |
| 40-65 | 中性 | 按计划定投 |
| ≤ 40 | 偏空 | 控制仓位，等企稳再投 |

单资产信号无法替代组合视角：**先看组合仓位上限，再看单资产分数**。

## 5. 交易纪律（执行层）

### 5.1 定投计划（每月）
1. 固定日期（发薪次日）按"基准月投额 × 各资产目标权重 × 估值倍数"执行；
2. 场外基金设**自动定投**，倍数调整每月初手动改一次即可（网站/Excel 会给出当月倍数）；
3. 单边下跌市不停投——低分位加倍投正是超额收益来源。

### 5.2 再平衡（每季度检查）
- 触发条件（满足其一）：① 单资产偏离目标 ±5 个百分点；② 距上次再平衡满 6 个月；
- 方法：卖超配买低配到目标权重；优先用新定投资金"只买不卖"实现（省税费）；
- 卫星仓调仓随动量排名月度自动进行，不算入再平衡。

### 5.3 止盈（只对高估触发，永远不因"涨多了"止盈）
- 核心宽基：估值分位 ≥ 80% 且组合股票仓位触顶 → 分 3 个月每月减 1/3 超限部分；
- 卫星仓：跌破 60 日线或跌出动量前 3 → 调出，收益落袋；
- 止盈资金进入债券/现金池，等待下一次低估加仓。

### 5.4 回撤加仓网格（手中有余粮时）
核心宽基自近期高点回撤达 **-15% / -25% / -35%** 时，各用预留资金的 1/3 加仓对应指数（要求：该指数估值分位同时 < 60%，否则不加）。

### 5.5 风控限额
| 限额 | 数值 |
|---|---|
| 单一行业卫星 | ≤ 10% |
| 单只基金 | ≤ 20% |
| 单一国家/地区（含核心） | ≤ 45% |
| 股票总仓位 | 60%-85% 区间运行 |
| QDII 溢价 | > 3% 拒买 |
| 信号陈旧 | > 10 个交易日暂停决策 |

## 6. 执行清单

**每日（5 分钟）**：打开网站看总览页是否有红色预警（溢价超限/信号陈旧/回撤提醒）。不交易。

**每月（30 分钟）**：
1. 看报告页的当月定投表 → 调整场外自动定投倍数；
2. 检查行业卫星动量排名是否变化（引擎已自动给出）；
3. 记录持仓流水到 Excel 看板。

**每季（1 小时）**：跑再平衡计算器 → 偏离超 ±5pp 则执行 → 在 Excel 记录本次再平衡。

**每年（半天）**：
1. 复核资产池与目标权重是否仍匹配人生阶段（资金期限变了要重设）；
2. 核对全部持仓基金的费率/规模/跟踪误差（有恶化则换同类替代）；
3. 复盘：过去一年每笔交易是否都能对应到手册规则，写 3 条改进。

## 7. 行为陷阱对照表（写给你的未来自己）

| 陷阱 | 手册对策 |
|---|---|
| 暴跌恐慌割肉 | 回撤网格只加不减；200 日线分位规则决定仓位，不由情绪决定 |
| 暴涨追热 | 卫星只买动量前3且需趋势门槛；高估区自动停投 |
| "这次不一样" | 历史分位就是"这次"的标尺；QDII 溢价超限一律拒买 |
| 频繁看盘频繁操作 | 每日只看预警，不产生交易动作；调仓只发生在规则触发时 |
| 一次性梭哈 | 新资金分 6-12 个月按定投计划入场 |
