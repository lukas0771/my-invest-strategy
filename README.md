# invest-strategy — 国内外基金/ETF 四维信号投资决策系统

一套面向**场外基金 + ETF** 投资者的完整决策工具链：策略手册 + 信号引擎 + 策略网站 + Excel 看板。
投资定位：3-10 年期限、最大回撤容忍 20-30% 的积极型组合，核心-卫星架构。

> ⚠️ **不构成投资建议。** 所有信号规则均为历史统计规律的简化表达；基金/指数代码仅为示例，交易前自查最新数据。

全部数据落 **SQLite 本地库**（`data/invest.db`），断网也可用缓存出报告。

## 快速开始

```bash
pip install -r requirements.txt

# 1) 配置 tushare token（可选但强烈推荐——解锁两融/北向/QDII溢价/基金净值/日经225）
copy .env.example .env       # 编辑 .env，填入 TUSHARE_TOKEN=你的token

# 2) 首次拉取数据（约3-8分钟，之后每日增量）
python -m src.cli fetch

# 3) 一键：刷新→信号→报告→回测
python -m src.cli all

# 4) 启动网站 → 浏览器打开 http://127.0.0.1:8000
python -m uvicorn webapp.main:app --host 127.0.0.1 --port 8000
#    每个交易日 16:30 自动刷新数据（DISABLE_SCHEDULER=1 关闭）
```

### 网站功能
- **策略总览**：打分卡热力表（四维分+总分+定投倍数+建议）、组合权重饼图、预警中心
- **估值温度**：各指数 10 年分位横条图 + PE 历史曲线
- **趋势动量**：12-1 月动量排名、200 日线位置、价格 vs 均线图
- **资金面**：两融余额、量能比、QDII 溢价监控（>3% 标红拒买）
- **宏观仪表**：PMI / M1-M2 剪刀差 / PPI / 美债10Y / 席勒PE
- **当前策略**：本月定投计划（含估值倍数）、目标权重、调仓说明
- **持仓跟踪**：录入持仓自动估值 → 偏离与再平衡调仓金额
- **历史回测**：净值曲线、年化/回撤/夏普、分年度收益
- **信号报告**：渲染最新 Markdown 报告
- **数据刷新**：手动按钮 + 每日 16:30 定时（APScheduler）

## 数据源与降级链

| 优先级 | 数据源 | 提供 | 依赖 |
|---|---|---|---|
| 1 | Tushare Pro（2000 分） | 指数行情+PE、两融、沪深港通、宏观、全球指数、基金净值 | `.env` 中 token |
| 2 | 中证指数官网 | 中证系指数行情+**官方滚动PE**（权威） | 免费直连 |
| 3 | AKShare/新浪 | 美股指数、恒生科技、创业板指、ETF 行情、宏观兜底 | 免费直连 |
| 4 | FRED / multpl 官网 | 美债10Y、标普500席勒PE | 免费直连 |

**无 token 也能跑**：估值用中证官网 PE（创业板指等无官方 PE 的用价格分位替代并标注）；
两融/北向/QDII溢价/场外基金净值缺失时对应信号优雅降级。**东财接口在部分网络被拒**，系统自动绕行。

> 注：北向资金 2024-08 起停止实时披露，体系改用两融+量能作为风险偏好代理（手册 §4.3）。

## 打分卡与核心规则（详见手册）

- **估值分位 → 定投倍数**：<20%→2x｜20-40%→1.5x｜40-60%→1x｜60-80%→0.5x｜≥80%→停投
- **行业卫星**：12-1 月动量前 3 名各配 4%/4%/2%，趋势分 <50 不得入选
- **组合仓位上限**：沪深300 分位 ≥60%→股票≤70%，≥80%→≤60%
- **再平衡**：单资产偏离目标 ±5pp 触发，每季至少检查一次
- **回撤网格**：核心宽基 -15%/-25%/-35% 分批加仓
- **QDII 溢价** > 3% 拒买

## 回测基准（2015-01 至 2026-09，141 个月，月度调仓）

| 策略 | 年化 | 最大回撤 | 夏普 |
|---|---:|---:|---:|
| 四维打分卡 | +6.4% | -19.1% | 0.44 |
| 核心固定（无卫星/择时） | +6.1% | -15.5% | 0.47 |
| 沪深300 买入持有 | +2.4% | -40.6% | 0.12 |
| 60/40 股债 | +3.5% | -24.4% | 0.18 |

诚实结论：打分卡相对"核心固定"的增量主要来自**回撤控制与仓位纪律**而非暴利；
相对沪深300 满仓，年化 +4pp、回撤减半。指数级模拟，不含申赎费/跟踪误差。

```

├── docs/strategy-handbook.md   # 策略手册（先读这个）

│   ├── main.py                 # FastAPI：API + 静态托管
```
